Удобный аддон для Разбойника, который помогает следить за энергией, комбо-поинтами и основными баффами и дебаффами во время боя.

- Отображение энергии и комбо-поинтов. 
- Таймеры важных способностей класса. 
- Контроль ядов на оружии и цели. 
- Звуковые предупреждения перед окончанием важных эффектов.
- Удобная настройка размера, положения и внешнего вида полос. 

Аддон особенно полезен для пве Разбойников, так как позволяет держать всю основную информацию по ротации прямо перед глазами. 
/sc - открывает окно настроек.
